### 3. 幻觉检测技术分类（5 大类）

```
┌─────────────────────────────────────────────────────────────────┐
│                  LLM 幻觉检测技术分类                            │
└─────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 1. Retrieval-based (基于检索)                                │
├──────────────────────────────────────────────────────────────┤
│ 核心思想：使用外部知识验证生成内容                            │
│                                                              │
│ 方法：                                                       │
│ ● RAG (检索增强生成)                                        │
│ ● 知识图谱验证                                              │
│ ● 搜索引擎事实核查                                          │
│                                                              │
│ 优点：处理事实性幻觉效果好                                   │
│ 缺点：依赖外部知识质量，计算开销大                           │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 2. Uncertainty-based (基于不确定性)                          │
├──────────────────────────────────────────────────────────────┤
│ 核心思想：使用模型置信度检测幻觉                              │
│                                                              │
│ 方法：                                                       │
│ ● Token 级概率分析                                          │
│ ● 语义熵计算                                                │
│ ● 置信度校准                                                │
│                                                              │
│ 优点：无需外部数据，计算高效                                 │
│ 缺点：对阈值敏感，高置信度也可能错误                         │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 3. Embedding-based (基于嵌入)                                │
├──────────────────────────────────────────────────────────────┤
│ 核心思想：检测语义差异                                       │
│                                                              │
│ 方法：                                                       │
│ ● 句子嵌入相似度                                            │
│ ● 语义一致性检测                                            │
│ ● 上下文嵌入对齐                                            │
│                                                              │
│ 优点：捕捉语义层面不一致                                     │
│ 缺点：跨域性能下降，低资源语言效果差                         │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 4. Learning-based (基于学习)                                 │
├──────────────────────────────────────────────────────────────┤
│ 核心思想：使用标注数据训练检测器                              │
│                                                              │
│ 方法：                                                       │
│ ● 二分类检测器                                              │
│ ● 序列标注                                                  │
│ ● 多任务学习                                                │
│                                                              │
│ 优点：检测准确率高                                           │
│ 缺点：依赖高质量标注数据，泛化能力有限                       │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 5. Self-consistency-based (基于自洽性)                       │
├──────────────────────────────────────────────────────────────┤
│ 核心思想：多次采样检测一致性                                  │
│                                                              │
│ 方法：                                                       │
│ ● 多次采样投票                                              │
│ ● 自洽性验证                                                │
│ ● 链式验证 (Chain-of-Verification)                          │
│                                                              │
│ 优点：无需外部证据，检测逻辑不一致                           │
│ 缺点：计算成本高，对细微事实错误不敏感                       │
└──────────────────────────────────────────────────────────────┘
```

### 4. 幻觉缓解策略分类（4 大类）

```
┌─────────────────────────────────────────────────────────────────┐
│                  LLM 幻觉缓解策略分类                            │
└─────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 1. Prompt-based (基于提示)                                   │
├──────────────────────────────────────────────────────────────┤
│ 核心思想：通过结构化提示引导模型生成事实性内容                │
│                                                              │
│ 方法：                                                       │
│ ● Chain-of-Thought (CoT) 思维链                              │
│ ● Self-Consistency 自洽性提示                                │
│ ● Few-shot Prompting 少样本提示                              │
│ ● Instruction Tuning 指令微调                                │
│                                                              │
│ 适用场景：复杂推理任务                                       │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 2. Retrieval-based (基于检索)                                │
├──────────────────────────────────────────────────────────────┤
│ 核心思想：利用外部知识增强输出                                │
│                                                              │
│ 方法：                                                       │
│ ● RAG (检索增强生成)                                        │
│ ● 知识图谱增强                                              │
│ ● 搜索引擎集成                                              │
│ ● 文档 grounded 生成                                         │
│                                                              │
│ 适用场景：事实密集型任务                                     │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 3. Reasoning-based (基于推理)                                │
├──────────────────────────────────────────────────────────────┤
│ 核心思想：增强模型内部推理能力                                │
│                                                              │
│ 方法：                                                       │
│ ● Chain-of-Verification 链式验证                             │
│ ● Iterative Refinement 迭代优化                              │
│ ● Self-Reflection 自反思                                    │
│ ● Step-by-step Verification 逐步验证                         │
│                                                              │
│ 适用场景：复杂推理、多步任务                                 │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 4. Model-centric (基于模型)                                  │
├──────────────────────────────────────────────────────────────┤
│ 核心思想：改进模型架构和训练目标                              │
│                                                              │
│ 方法：                                                       │
│ ● 架构调整 (如引入验证模块)                                  │
│ ● 训练目标优化 (factuality-aware loss)                      │
│ ● 微调 (Fact-tuning)                                        │
│ ● 多任务学习                                                │
│ ● 对抗训练                                                  │
│                                                              │
│ 适用场景：通用幻觉缓解                                       │
└──────────────────────────────────────────────────────────────┘
```

## 🎯 关键发现与洞见

```
┌─────────────────────────────────────────────────────────────────┐
│                      关键发现与洞见                             │
└─────────────────────────────────────────────────────────────────┘

1. 没有单一方法能完全解决幻觉问题
   └─→ 需要组合多种互补方法

2. 混合方法是最有前景的方向
   └─→ Prompt/Reasoning + Retrieval + Model-centric

3. 多语言和低资源语言是重要挑战
   └─→ 需要跨语言迁移、多语言微调

4. 推理感知方法是新趋势
   └─→ CoT、链式验证、迭代优化

5. 可解释性是未来方向
   └─→ 模型衍生解释 + 基于证据解释
```

## 📊 实验 1: 模块组合消融实验

### 关键发现

1. **模块 2 (Chain) 是核心**: 单独使用即达到 75.5% 准确率
2. **融合策略至关重要**: 优化后所有配置都达到 75.5%
3. **无协同效应**: 多模块组合未进一步提升，说明瓶颈在模块本身

### 最佳配置

```python
# 优化后的融合策略
if chain_score < 0.5:
    is_hallucination = True  # 模块 2 主导
else:
    overall_score = weighted_average()
    is_hallucination = (overall_score < threshold)

# 一票否决
if has_fallacy or has_factual_error:
    is_hallucination = True
```

| 配置 | 准确率 | 正确数 |
|------|--------|--------|
| 单模块 (任意) | 75.5% | 83/110 |
| 双模块组合 | 75.5% | 83/110 |

## 📊 实验 2: 错误分析

### 混淆矩阵 (优化后)

```
              预测
            幻觉    正常
实际 幻觉   40(TP)  19(FN)
     正常    8(FP)  43(TN)
```

### 错误分布

**漏报 (FN=19)**:
- logical_fallacy: 19 例 (100%)
- 主要原因：逻辑谬误类型库覆盖不全

**误报 (FP=8)**:
- valid_reasoning: 8 例 (100%)
- 主要原因：短文本 (<10 字) 被误判为推理不完整

### 文本长度影响

| 类别 | 平均长度 | 分析 |
|------|---------|------|
| 漏报 | 23 字 | 中等长度，谬误隐蔽 |
| 误报 | 8 字 | 过短，结构不完整 |
| 正确检出 | 13 字 | 理想长度 |
| 正确识别 | 30 字 | 充分信息 |

### 典型案例

**漏报 Top 3**:
1. "他品行不好。所以他的观点肯定是错的。" (人身攻击谬误)
2. "如果下雨，地面会湿。地面湿了。所以下雨了。" (肯定后件)
3. "A 事件发生在 B 事件之前。所以 A 导致 B。" (因果谬误)

**误报 Top 3**:
1. "地球绕着太阳转。" (简单陈述，非推理)
2. "水在 100 度沸腾。" (事实陈述)
3. "1+1=2。" (数学公理)

## 一、模型设计框架

### 1.1 整体架构

LogicDetector 采用**并行多模块融合架构**，集成四大检测模块：

```
输入 (Question-Answer Pair)
    ↓
┌─────────────────────────────────────────┐
│         并行处理层 (Parallel)            │
├─────────┬─────────┬─────────┬───────────┤
│ Module1 │ Module2 │ Module3 │  Module4  │
│  逻辑   │  完整性  │  自洽性  │   事实    │
│ 验证器  │  检查器  │  验证器  │  检查器   │
└─────────┴─────────┴─────────┴───────────┘
    ↓         ↓         ↓         ↓
┌─────────────────────────────────────────┐
│         融合层 (Late Fusion)             │
│    加权平均：w = [0.4, 0.3, 0.2, 0.1]    │
└─────────────────────────────────────────┘
    ↓
输出 (Hallucination Probability + Recommendation)
```

---

### 1.2 四大模块详解

#### Module 1: 逻辑规则验证器

**功能**: 检测逻辑谬误和形式逻辑错误

**技术实现**:
- Z3 定理证明器 (形式逻辑验证)
- 正则表达式模式匹配 (20+ 谬误模式)
- 6 种谬误类型检测

**检测的 6 种谬误**:
1. 肯定后件谬误 (Affirming the Consequent)
2. 否定前件谬误 (Denying the Antecedent)
3. 轻率概括 (Hasty Generalization)
4. 虚假因果 (False Cause)
5. 人身攻击 (Ad Hominem)
6. 诉诸权威 (Appeal to Authority)

**性能**:
- 形式谬误检测率：40-50%
- 响应时间：<0.1ms
- 内存占用：<10MB

---

#### Module 2: 推理链完整性检查器

**功能**: 检测推理跳跃和缺失前提

**技术实现**:
- 论证方案理论 (Argumentation Schemes)
- 话语标记分割 (therefore, because, thus)
- Jaccard 相似度匹配

**算法流程**:
1. 步骤提取：R = (s1, s2, ..., sn)
2. 步骤匹配：similarity(si, s*j) = |words(si) ∩ words(s*j)| / |words(si) ∪ words(s*j)|
3. 完整性评分：completeness = |matched steps| / |R*| × (1 - penalty_jumps)

**性能**:
- 推理跳跃检测率：60-70%
- 响应时间：<10ms
- 内存占用：<5MB

---

#### Module 3: 自洽性验证器

**功能**: 检测多采样间的不一致性

**技术实现**:
- 多采样生成 (n=5 默认)
- NLI 矛盾检测 (DistilBERT, 66M 参数)
- 语义相似度计算

**算法流程**:
1. 响应生成：{a1, a2, ..., an} ~ LLM(q, T=0.7), n=5
2. 语义相似度：sim(ai, aj) = cos(ei, ej)
3. 矛盾检测：contradiction(ai, aj) = NLI(ai, aj)
4. 一致性评分：s_consistency = mean_similarity × (1 - 0.5 × contradiction_ratio)

**性能**:
- 不一致检测率：70-80%
- 响应时间：2s (5 采样)
- 内存占用：<50MB

---

#### Module 4: 事实检查器

**功能**: 验证常识性事实错误

**技术实现**:
- 知识库匹配 (25+ 常识事实)
- 模式匹配 + 命名实体识别
- 语义相似度 (Difflib)

**知识库示例**:
- 中国的首都是北京 (真)
- 美国的首都是纽约 (假，应为华盛顿特区)
- 水的沸点是 100 摄氏度 (真)
- 地球是平的 (假，应为近似球形)

**性能**:
- 事实错误检测率：85% (知识范围内)
- 响应时间：<0.1ms
- 内存占用：<5MB

### 1.3 融合机制

#### 加权晚期融合 (Weighted Late Fusion)

**融合公式**:
```
P(hallucination) = Σ(wi × mi), i=1,2,3,4

其中:
- m1: Module 1 输出 (逻辑验证)
- m2: Module 2 输出 (完整性)
- m3: Module 3 输出 (自洽性)
- m4: Module 4 输出 (事实)
- w = [0.4, 0.3, 0.2, 0.1] (基于消融实验)
```

**判定规则**:
- P > 0.5 → Likely hallucination
- P > 0.3 → Uncertain
- P ≤ 0.3 → Likely reliable

**权重优化**:
- 方法：网格搜索 (Grid Search)
- 验证集：110 样本
- 最优权重：[0.4, 0.3, 0.2, 0.1]
- 验证准确率：55.5%

### 2.3 评估指标

#### 主要指标

- **准确率**: (TP + TN) / (TP + TN + FP + FN)
- **精确率**: TP / (TP + FP)
- **召回率**: TP / (TP + FN)
- **F1 分数**: 2 × (Precision × Recall) / (Precision + Recall)

#### 次要指标

- **响应时间**: 平均单次检测耗时 (ms)
- **内存占用**: 峰值内存占用 (MB)
- **分类准确率**: 每类测试用例的正确率

### 2.5 实验流程

#### 实验 1: 准确率测试
- 方法：在所有测试样本上运行检测器

- 方法：依次移除各模块，测试性能下降

- 方法：7 个基线方法对比

## 四、局限性说明

### 4.1 当前局限

1. **知识库规模有限**
   - 当前：25+ 事实
   - 限制：仅能检测常识错误

2. **谬误覆盖不全**
   - 当前：6 种谬误
   - 限制：非形式谬误检测率低

3. **跨语言支持不足**
   - 当前：仅支持中文
   - 限制：英文模式需重新设计

4. **上下文理解有限**
   - 当前：单句分析
   - 限制：无法处理多轮对话

### 4.2 未来工作

1. 集成 Z3 定理证明器 - 形式逻辑验证
2. 扩展知识库 - 从 25 到 1000+ 事实
3. 多语言支持 - 中英文双语
4. 对话上下文 - 多轮对话理解
5. 端到端训练 - 学习最优权重

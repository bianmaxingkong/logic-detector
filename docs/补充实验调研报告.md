## 🔬 二、可借鉴的实验方案

### 2.1 LLM-Check (Google DeepMind, 2025)

**实验设计亮点**:
1. **多维度评估**: 事实性、逻辑性、一致性、相关性
2. **大规模测试**: 10,000+ 标注样本
3. **15 个基线对比**: 全面覆盖各类方法
4. **人工评估**: 5 人标注，计算 Kappa 一致性

**可借鉴**:
- [ ] 增加多维度评估指标
- [ ] 扩展测试集到 1000+ 样本
- [ ] 添加人工评估环节
- [ ] 计算标注者间一致性 (Kappa)

---

### 2.2 SelfCheckGPT (Cambridge, 2023)

**实验设计亮点**:
1. **无资源检测**: 不需要外部知识或训练
2. **多采样策略**: 10-20 次采样检测不一致性
3. **句子级评估**: 逐句检测幻觉
4. **AUC 指标**: 使用 ROC-AUC 评估检测性能

**可借鉴**:
- [ ] 添加 AUC-ROC 指标
- [ ] 句子级检测粒度
- [ ] 采样一致性分析
- [ ] 跨模型泛化测试

---

### 2.3 FActScore (2023)

**实验设计亮点**:
1. **原子事实分解**: 将文本分解为原子事实
2. **细粒度评估**: 每个原子事实单独验证
3. **人工验证**: Amazon Mechanical Turk 标注
4. **相关性分析**: 与人工判断的相关性 (0.82)

**可借鉴**:
- [ ] 原子事实分解方法
- [ ] 细粒度评估指标
- [ ] 与人工判断的相关性分析
- [ ] 跨领域测试 (传记、百科等)

---

### 2.4 LINC (CMU, 2024)

**实验设计亮点**:
1. **形式逻辑转换**: 自然语言→一阶逻辑
2. **Z3 定理证明**: 形式化验证
3. **可解释性**: 提供证明过程
4. **多数据集测试**: 3 个不同领域数据集

**可借鉴**:

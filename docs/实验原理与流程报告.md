## 🔍 核心问题：不调用大模型，怎么做幻觉检测？

### 答案：LogicDetector **检测的是推理过程**，不是生成内容

**关键区别**：

| 方法 | 输入 | 输出 | 是否需要大模型 |
|------|------|------|---------------|
| **传统幻觉检测** | 大模型生成的回答 | 判断是否幻觉 | ❌ 需要 (生成内容) |
| **LogicDetector** | 任意推理文本 | 判断逻辑是否有效 | ✅ **不需要** (分析已有文本) |

---

## 📊 实验设计原理

### 1. 检测对象

LogicDetector 检测的是**推理文本的逻辑有效性**，而不是检测大模型生成的内容。

**示例**：

```
输入文本："如果明天下雨，比赛取消。明天下雨。因此比赛取消。"
检测：✓ 有效推理 (肯定前件)

输入文本："如果明天下雨，比赛取消。比赛取消。因此明天下雨。"
检测：✗ 逻辑谬误 (肯定后件)
```

**关键点**：
- ✅ 不需要大模型生成内容
- ✅ 只需要分析给定的推理文本
- ✅ 基于逻辑规则和模式匹配

## 💻 代码实现逻辑

### 核心检测流程

```python
# detector.py - 核心逻辑

class LogicDetector:
    def analyze(self, text: str, reasoning_type: str = "deductive"):
        """
        分析推理文本是否存在逻辑问题
        
        Args:
            text: 待检测的推理文本
            reasoning_type: 推理类型 (deductive/inductive/causal)
        
        Returns:
            DetectionResult: 检测结果
        """
        
        # ========== 模块 1: 逻辑规则验证 ==========
        fallacies = self.logic_validator.validate(text)
        # 使用 Z3 定理证明器 + 正则模式匹配
        # 示例模式：r"如果.*那么.*因此" (肯定后件)
        
        # ========== 模块 2: 推理链完整性 ==========
        chain_analysis = self.chain_checker.check_completeness(
            text, reasoning_type
        )
        # 提取前提 - 结论结构，检查是否完整
        
        # ========== 模块 3: 自洽性验证 ==========
        # 可选：使用小模型生成变体并检查矛盾
        consistency_score = self.consistency_verifier.verify(text)
        
        # ========== 模块 4: 事实检查 ==========
        factual_errors = self.fact_checker.get_factual_errors(text)
        # 匹配常识知识库
        
        # ========== 多模块融合 ==========
        overall_score = (
            0.4 * logic_score +      # 模块 1
            0.3 * chain_score +      # 模块 2
            0.2 * consistency_score + # 模块 3
            0.1 * fact_score         # 模块 4
        )
        
        # 一票否决：有明确谬误直接判定为幻觉
        if fallacies or factual_errors:
            is_hallucination = True
        
        return DetectionResult(...)
```

## 🧪 实验流程

### 步骤 1: 加载测试集

```python
# 读取 JSON 文件
with open('test_set_full_600.json', 'r') as f:
    data = json.load(f)

```

### 步骤 2: 逐条检测

```python
detector = LogicDetector()

for case in test_cases:
    text = case['text']           # 推理文本
    true_label = case['label']    # 真实标签 (valid/hallucination)
    
    # 调用检测器
    result = detector.analyze(text)
    pred_label = 'hallucination' if result.is_hallucination else 'valid'
    
    # 统计
    if pred_label == true_label:
        correct += 1
```

### 步骤 3: 计算指标

```python
# 准确率
accuracy = correct / total

# 精确率、召回率、F1
tp = true_positive  # 正确检出的幻觉
fp = false_positive # 误判为幻觉
fn = false_negative # 漏检的幻觉

precision = tp / (tp + fp)
recall = tp / (tp + fn)
f1 = 2 * precision * recall / (precision + recall)
```

## 🔑 关键问题解答

### Q1: 为什么不需要大模型？

**A**: LogicDetector 是**分析器**，不是**生成器**。

- **生成器** (如 GPT-4): 需要生成文本 → 需要大模型
- **分析器** (如 LogicDetector): 分析已有文本的逻辑 → 用规则 + 小模型

**类比**：
- 语法检查器 (Grammarly) 不需要生成文章，只需要检查语法
- LogicDetector 不需要生成推理，只需要检查逻辑

### Q3: 81.7% 准确率是怎么来的？

**A**: 基于 600 条测试集的实验结果：

```
总样本：600 条
- 逻辑谬误：300 条
- 有效推理：250 条
- 事实错误：50 条

检测结果:
- 正确检出：490 条
- 错误判断：110 条

准确率 = 490 / 600 = 81.7%
```

**详细指标**：
- 精确率：88.7% (检出的幻觉中 88.7% 确实是幻觉)
- 召回率：78.6% (所有幻觉中检出了 78.6%)
- F1 分数：83.3%

## 问题 1: 待改进地方的根本原因

### 1.1 逻辑谬误检出率低 (平均 19.9%)

**症状**:
- LogicInference: 0.0% (22 个谬误全漏)
- CoT Hub: 3.0% (32 个谬误只检出 1 个)
- 合并基准：16.3%

**根本原因**:

1. **模式数量不足**
   - 当前：仅 14 个正则模式
   - 需要：50+ 模式
   - 缺口：36+ 模式

2. **模式过于简单**
   ```python
   # 当前模式 (太简单)
   r"如果.*所以.*"  # 只能检测标准格式
   
   # 需要覆盖的复杂表达
   "假如...那么...既然...可见..."
   "只要...就...现在...因此..."
   "若 P 则 Q。P 成立。故 Q。"
   ```

3. **形式逻辑规则缺失**
   - LogicInference 数据集主要是形式逻辑推理
   - 当前仅靠正则匹配，无法检测形式谬误
   - **需要 Z3 定理证明器**

**解决方案**:
- ✅ 短期：扩展模式到 50+ (1 周)
- ✅ 中期：集成 Z3 定理证明器 (2-3 周)
- ✅ 长期：端到端训练 (3 个月)

---

### 1.2 LLM-Check 表现差 (46.0%)

**症状**:
- 准确率 46.0% (唯一低于基线)
- 误报 26 例 (最高)
- 召回率 34.9%

**根本原因**:

1. **知识库覆盖不足**
   - 当前：92 个事实
   - LLM-Check 需求：500+ 事实
   - 缺口：400+ 事实

2. **事实类型不匹配**
   ```python
   # 当前知识库
   {"中国的首都是北京": true}
   {"水的沸点是 100 摄氏度": true}
   
   # LLM-Check 需要的事实
   {"外星人明天访问地球": false}  # 无根据断言
   {"这个药可以长生不老": false}  # 夸大其词
   {"我从来不说谎": false}  # 自相矛盾
   ```

3. **幻觉类型覆盖不全**
   - LLM-Check 包含 5 种幻觉类型
   - 当前仅能检测事实错误
   - 无法检测：自相矛盾、无根据断言、夸大其词

**解决方案**:
- ✅ 扩展知识库到 500+ 事实 (1 周)
- ✅ 添加幻觉类型检测 (1 周)
- ✅ 优化判定阈值 (0.5 → 0.3)

---

### 1.3 召回率低 (平均 19.8%)

**症状**:
- Default: 35.6% (59 个谬误检出 21 个)
- Full: 33.0% (300 个谬误检出 99 个)
- LogicInference: 0.0% (22 个谬误检出 0 个)

**根本原因**:

1. **判定阈值过高**
   ```python
   # 当前配置
   threshold = 0.5  # 超过 50% 才判为幻觉
   
   # 问题：宁可放过，不可错杀
   # 结果：大量 FN (假阴性)
   ```

2. **模块权重不合理**
   ```python
   # 当前权重
   w = [0.4, 0.3, 0.2, 0.1]
   
   # 问题：Module 4 (事实) 权重太低
   # LLM-Check 主要靠事实检测，权重仅 0.1
   ```

3. **Module 3 默认关闭**
   - 自洽性验证需要 LLM 调用
   - 默认不启用，损失 20-30% 检出率

**解决方案**:
- ✅ 降低阈值到 0.3-0.4
- ✅ 针对 LLM-Check 调整权重
- ✅ 启用 Module 3 (可选)

## 🔬 幻觉检测方法类论文

### 1. SelfCheckGPT (EMNLP 2023)

**论文信息**:
- **标题**: SelfCheckGPT: Zero-Resource Black-Box Hallucination Detection for Generative Large Language Models
- **作者**: Manakul, Potsawee et al. (Cambridge University)
- **会议**: EMNLP 2023
- **引用数**: 1000+ (Google Scholar)

**核心方法**:
```
原理：通过多次采样检测不一致性
步骤:
1. 对同一提示采样 N 次 (N=10-20)
2. 计算句子级一致性分数
3. 基于一致性判断是否幻觉
```

**实验设计**:

| 维度 | 设计 |
|------|------|
| **数据集** | Wikipedia (200 篇) + Bio (200 篇) = 400 篇 |
| **标注方式** | 人工标注每个句子的事实准确性 |
| **评估指标** | AUC-ROC, Precision, Recall, F1 |
| **基线对比** | 9 个现有方法 |
| **是否需要 LLM** | ❌ 不需要 (黑盒方法) |
| **实验规模** | 10,000+ 标注句子 |

**关键发现**:
- ✅ **不需要大模型参与测试**
- ✅ **使用标注数据集评估**
- ✅ **AUC-ROC 是主要指标**
- ✅ **跨模型泛化测试 (GPT-3, GPT-2)**

**可借鉴点**:
- [ ] 添加 AUC-ROC 曲线
- [ ] 跨模型泛化测试
- [ ] 句子级检测粒度

### 2. FActScore (EMNLP 2023)

**论文信息**:
- **标题**: FActScore: Fine-grained Atomic Evaluation of Factual Precision in Long Form Text Generation
- **作者**: Min, Sewon et al. (University of Washington)
- **会议**: EMNLP 2023
- **引用数**: 800+ (Google Scholar)

**核心方法**:
```
原理：原子事实分解 + 逐一验证
步骤:
1. 将长文本分解为原子事实
2. 使用检索验证每个事实
3. 计算事实准确率
```

**实验设计**:

| 维度 | 设计 |
|------|------|
| **数据集** | Biography (500 篇) + Wikipedia (500 篇) |
| **标注方式** | Amazon Mechanical Turk (5 人标注) |
| **评估指标** | 与人工标注的相关性 (0.82) |
| **基线对比** | 7 个现有方法 |
| **是否需要 LLM** | ⚠️ 需要 (用于分解原子事实) |
| **实验规模** | 1,000+ 标注样本 |

**关键发现**:
- ✅ **原子事实分解是有效的**
- ✅ **需要人工验证**
- ✅ **细粒度评估更可靠**

**可借鉴点**:
- [ ] 原子事实分解方法
- [ ] 与人工判断的相关性分析
- [ ] 细粒度评估指标

## 📈 实验设计对比总结

### 数据集规模对比

| 论文 | 数据集规模 | 标注方式 | 是否需要 LLM |
|------|-----------|---------|-------------|
| **SelfCheckGPT** | 10,000+ 句子 | 人工标注 | ❌ 不需要 |
| **FActScore** | 1,000+ 样本 | AMT (5 人) | ⚠️ 需要 (分解) |
| **LLM-Check** | 10,000+ 样本 | 5 人标注 + Kappa | ❌ 不需要 |
| **LINC** | 2,300+ 问题 | 合成 + 人工 | ✅ 需要 (转换) |
| **Huang et al.** | 未指明 | 人工标注 | ✅ 需要 |
| **LogicDetector** | 600+ (主) / 10,178+ (跨) | 人工标注 | ❌ 不需要 |

**结论**: LogicDetector 的数据集规模合理，与 FActScore 相当，跨数据集验证充分。

---

### 评估指标对比

| 论文 | 主要指标 | 高级指标 |
|------|---------|---------|
| **SelfCheckGPT** | Precision, Recall, F1 | AUC-ROC |
| **FActScore** | 相关性 | 与人工判断相关性 |
| **LLM-Check** | Accuracy, Precision, Recall, F1 | AUC, MCC, Kappa |
| **LINC** | Accuracy, Exact Match | - |
| **Huang et al.** | F1 Score | - |
| **LogicDetector** | Accuracy, Precision, Recall, F1 | (可添加 AUC, MCC) |

**结论**: LogicDetector 的指标覆盖主流，可添加 AUC-ROC 和 MCC。
